Stack / LIFO

PUSH(value)

if stack is full: stop (overflow)
TOP ← TOP + 1
STACK[TOP] ← value
display updated stack

POP()

if TOP = -1: stop (underflow)
value ← STACK[TOP]
TOP ← TOP - 1
display updated stack

Queue / FIFO

ENQUEUE(value)

if queue is full: stop (overflow)
append value to the rear
display updated queue

DEQUEUE()

if queue is empty: stop (underflow)
remove the front value
shift remaining values forward
display updated queue
